EXETER TECH SOLUTIONS - CLOUDCANNON SETUP

This version preserves the existing static website and adds a visual editing
layer for CloudCannon.

After uploading or committing these files:

1. In CloudCannon, open Site Settings > Details.
2. Set Static Site Generator to Static Site if it is not already selected.
3. Ensure the site uses Hosted mode so CloudCannon can build a preview.
4. Trigger a new build/sync.
5. Open Website pages and select a page.
6. Choose Visual Editor. Editable text, buttons and suitable photographs will
   be outlined and can be selected directly on the page.

The Content Editor is intentionally disabled for the HTML page collection.
Plain HTML pages contain layout code, so the Visual Editor is the safe editing
interface. The Source Editor remains available for technical maintenance.

Protected content:

- Navigation and footer structure
- Forms, fields and validation text
- Search results generated by JavaScript
- Scripts and styles
- Decorative images and icons

Only visually outlined regions should be edited in CloudCannon.
